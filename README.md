# Diabetes Prediction Using Logistic Regression

## 1. Project Overview
This project predicts whether a person has diabetes using Machine Learning. Logistic Regression is used to classify the person into two categories: diabetic or non-diabetic.

## 2. Objective
To build a Machine Learning classification model that predicts diabetes based on medical features.

## 3. Dataset
dataset link :- https://raw.githubusercontent.com/plotly/datasets/master/diabetes.csv
Dataset: Diabetes Prediction Dataset (Pima Indians Diabetes Dataset)

The dataset contains the following columns:

- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age
- Outcome

Target Variable: Outcome

- 0 = No Diabetes
- 1 = Diabetes

## 4. Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 5. Machine Learning Algorithm
Logistic Regression

Logistic Regression is a supervised Machine Learning algorithm used for classification problems. It predicts the probability of a data point belonging to a particular class.

## 6. Project Workflow
1. Import required libraries.
2. Load the dataset.
3. Perform data inspection.
4. Check missing values and duplicate records.
5. Separate input features and target variable.
6. Split the dataset into training and testing sets.
7. Train the Logistic Regression model.
8. Make predictions.
9. Test the model using custom input.
10. Evaluate model performance.

## 7. Model Evaluation
The model is evaluated using the following metrics:

- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-Score

## 8. Conclusion
The Logistic Regression model was successfully trained to predict diabetes using patient-related features. It classifies the input into diabetic or non-diabetic categories.

The model is developed for educational purposes and is not intended for medical diagnosis.
